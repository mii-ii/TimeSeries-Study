# 과제_크로스엔트로피함수

---

### 1. '크로스 엔트로피'함수라고 명명한 이유?

'엔트로피'는 **불확실성**이나 **정보량**을 뜻한다.

- **엔트로피(Entropy):** 나 혼자 가지고 있는 정보의 불확실한 정도
- **크로스(Cross):** 두 개의 확률 분포(정답 분포와 내 모델이 예측한 분포)를 '교차'해서 비교한다는 뜻

**"실제 정답(P)"과 "내 모델의 예측값(Q)"이 얼마나 다른지(얼마나 교차되는지)를 정보량으로 계산한 것**이라서 교차 엔트로피(Cross-Entropy)라고 부른다.

- 모델이 정답을 완벽하게 맞히면? 두 분포가 같아져서 엔트로피 값이 최소가 된다. (손실 0)
- 모델이 엉뚱한 답을 내놓으면? 두 분포의 차이가 커져서 엔트로피 값이 엄청 커진다. (손실 증가)

### 2. 크로스엔트로피함수밖에 없는가?

손실 함수(Loss Function)의 종류는 많다. 풀려는 문제에 따라 선택하여 사용한다.

- **평균 제곱 오차 (MSE, Mean Squared Error):** 주로 주식 가격이나 온도 예측 같은 **회귀(Regression)** 문제에서 많이 사용함. 
(예: 정답이 30도인데 20도라고 예측했으면 그 차이의 제곱만큼 벌점)
- **힌지 손실 (Hinge Loss):** 서포트 벡터 머신(SVM) 같은 곳에서 썼던 함수예요.
- **쿨백-라이블러 발산 (KL Divergence):** 두 확률 분포의 차이를 계산할 때 쓰는데, 크로스 엔트로피와 비슷함

### 3. 왜 크로스엔트로피함수를 인위적으로 만들어 사용하는가?

**1. 통계학적 근거: 최대 우도 추정 (MLE)**
• **목표:** 내 모델이 정답을 맞힐 확률(**우도**, Likelihood)을 **최대화(Maximize)** 하는 것.
• **문제점:** 확률(0~1 사이의 소수)을 계속 곱하면 값이 너무 작아져서 컴퓨터가 계산하기 힘듦 (언더플로우).
• **해결책:** 로그(Log)를 취해서 곱하기를 **더하기**로 바꿈. → 계산이 쉽고 안정적임.
• **결론 (수식의 변환):**
    ◦ "확률(P)을 최대화한다"
    ◦ = "로그 확률(log P)을 최대화한다"
    ◦ = **"마이너스 로그 확률(-log P)을 최소화한다"**
    ◦ ∴**-log P의 합**이 바로 **크로스 엔트로피** 수식임.

**2. 학습 효율성: 기울기 소실(Gradient Vanishing) 방지**
• **MSE(제곱 오차)를 쓸 경우:**
    ◦ 모델이 예측을 완전히 틀려도(예: 정답 1인데 0.0001 예측), 그래프의 기울기(미분값)가 거의 0에 가까움.
    ◦ **결과:** 오차가 큰데도 "얼마나 고쳐야 할지"를 몰라서 학습이 멈춰버림 (**기울기 소실**).
• **크로스 엔트로피를 쓸 경우:**
    ◦ 모델이 틀릴수록(정답과 멀어질수록) 그래프의 기울기가 **아주 가파르게** 솟구침.
    ◦ **결과:** 강한 벌점(큰 기울기)을 줌. 
    ◦ 모델이 빠르게 정답 방향으로 학습됨.
