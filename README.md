#XOR 신경망 공간 변환 시각화

단층 퍼셉트론으로 해결할 수 없는 XOR 문제를, 은닉층(Hidden Layer)을 추가하여 해결하는 과정을 파이썬으로 구현했습니다.
가중치를 수동으로 설정하여 데이터 공간이 어떻게 변형되고 선형 분리가 가능해지는지 시각적으로 확인하였습니다.

1.사용 기술
Python 3
numpy: 행렬 연산 및 벡터 계산
matplotlib: 데이터 공간 및 결정 경계(Decision Boundary) 시각화

2.주요 로직
데이터셋 생성 (XOR)
입력 데이터 X는 (0,0), (1,1), (0,1), (1,0) 네 가지 영역 근처에 분포하도록 생성했습니다.

XOR 논리: 서로 다른 값을 가지면 Red (Class 1), 같은 값을 가지면 Blue (Class 0)로 라벨링 했습니다.

가중치 설계 (Weight & Bias)
학습 대신, 입력 공간을 효과적으로 변형할 수 있는 가중치를 수동으로 적용했습니다.

W1 (가중치): [[-2.0, 2.0], [-2.0, 2.0]]

b1 (편향): [3.0, -1.0]

활성화 함수: 시그모이드(Sigmoid)를 사용하여 비선형성을 추가했습니다.

최적 경계선(Boundary) 자동 계산
은닉층을 통과한 데이터(H)를 기준으로, 두 클래스를 가장 잘 나누는 경계선을 자동으로 계산했습니다.

출력층 가중치(w31, w32)를 1.0으로 고정.

Blue 팀의 최대 점수와 Red 팀의 최소 점수의 **중간값(Midpoint)**을 임계값으로 산출.

이를 통해 최적의 바이어스 b3를 역산하여 결정 경계(Decision Boundary)를 그렸습니다.

3. 실행 결과

코드를 실행하면 내부 연산을 통해 계산된 점수와 최적의 바이어스가 출력됩니다.

적용된 가중치(W) : [[-2.  2.] [-2.  2.]]
적용된 바이어스(b) : [3. -1.]

파란 팀 최대 점수: 1.0371
빨간 팀 최소 점수: 1.9367

자동으로 계산된 최적 바이어스(b3): -1.4869

4. 시각화 결과
Input Layer: 초기 데이터는 대각선 방향으로 분포하여 직선 하나로 나눌 수 없는 상태입니다.
Hidden Layer: 가중치 연산과 시그모이드를 거친 데이터가 한쪽 구석으로 모이며, 직선 하나로 깔끔하게 분류 가능한(Linear Separable) 형태로 변환된 것을 확인할 수 있습니다.
